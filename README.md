<h1>GAME/BANK DESGIN</h1>
<B1>
One thing about me, I’ve always been someone who likes creating and fixing things.
Whether it’s hardware or software, I take pride in it.

Because it reflects the time and effort I’ve put in.

Recently, I’ve been using AI Studio to help bring my ideas to life to actually visualise what I’ve been thinking.

One of those ideas I’m working on is a banking app. It’s still in development, but I chose to share it because it connects to something I’m genuinely passionate about gaming.

Right now, with how much exposure our generation has to technology, attention spans are getting shorter.. and financial literacy isn’t really being talked about enough.

So for me, it comes back to the WHY.

How do I create something that actually helps?

The goal with this app is to help bridge that gap for youth. I’m designing it with a gaming approach using levels, classes, and clans. So it feels engaging, not overwhelming. 

Using AI Studio to build and visualise it, and n8n to support the back-end especially around login and security. Because when it comes to finances, security has to be solid.

The idea is to help young people organise their money, while progressing through something that feels familiar. Like a game. They can earn in-app incentives through saving, and stay accountable through their clans. Where everyone supports each other and stays on track.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
